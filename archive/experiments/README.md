# Archived Experiments

This folder preserves lightweight intermediate model-development work that is useful for audit history but too noisy for the portfolio-facing project root.

The active reproducible pipeline is documented in `REPRODUCIBILITY.md` and uses:

- `src/build_metadata.py`
- `src/create_splits.py`
- `src/train_final_model.py`

The archived scripts, metrics, and figures are not required to reproduce the final selected Random Forest model. Large generated feature caches and neural-network checkpoints are intentionally excluded from the public release.
